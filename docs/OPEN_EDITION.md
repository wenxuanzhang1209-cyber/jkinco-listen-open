# 开源版说明

本仓库是筑听的**开源本地版（Open Edition）**，定位是：

- 100% 本地运行，无需任何 API Key；
- 录音 → 转写 → 场景识别 → 纪要 → 导出完整闭环；
- 模型、模板、历史数据全部属于使用者自己。

## 边界

- 本仓库只包含开源本地版；
- 开源版不提供云端实时流式字幕（录音上传转写为旗舰能力）；
- 与任何商业/内部版本相互独立，互不共享代码与配置；
- 本仓库的 CI 红线扫描保证云端模型痕迹、密钥、生产信息永不进入开源仓库。

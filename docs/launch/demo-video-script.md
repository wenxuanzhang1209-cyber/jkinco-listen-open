# 60 秒演示视频脚本

目标：让没看过项目的人在 60 秒内理解“自托管实时会议 → 本地字幕 → 可归档纪要”，
并产生“我也要装一个”的冲动。建议 16:9，同时裁一版 9:16 竖屏。

## 分镜

| 时间 | 画面 | 台词/字幕 |
|---|---|---|
| 0–5s | 标题卡：Meetings live. Minutes private. | “开会时实时出字幕，散会后直接拿到纪要。” |
| 5–12s | 进入实时会议，两人入会，打开麦克风 | “用自托管房间开会，不把会议交给第三方。” |
| 12–24s | 侧栏出现本机流式字幕，画面不切走 | “字幕在本机生成，实时落入同级转写。” |
| 24–34s | 屏幕共享 + 会议结束，进入纪要生成 | “屏幕共享、聊天、会后自动生成结构化纪要。” |
| 34–43s | 展示通用会议纪要：结论、责任人、待办 | “先讲通用会议，也能识别面试、客户拜访和工程例会。” |
| 43–50s | 点击导出 Word/PDF | “一键导出能归档、能发送的 Word / PDF。” |
| 50–55s | 打开终端，敲 docker compose up | “部署？一条命令，LiveKit 也一起启动。” |
| 55–60s | 正式 App 三端下载页 + 开源仓库 | “想直接用：获取正式 App；想自托管：MIT 开源版 Star 支持下一版。” |

## 制作清单

- 用完全虚构的 30–60 秒会议片段，人物、公司、项目名全部脱敏；
- 第一镜头必须出现“实时字幕”，不要先展示录音上传；
- 通用会议放在主叙事，工程例会只作为 5 秒专业能力证明；
- 字幕用中英双语；
- 标题卡用 `docs/social-preview.png` 同款视觉；
- 结尾同时给出正式 App 三端下载页和开源仓库，口播里明确“立即使用”与“自托管”的区别；
- 上传 Bilibili（国内）+ YouTube（海外），两个链接都放进发布文案。

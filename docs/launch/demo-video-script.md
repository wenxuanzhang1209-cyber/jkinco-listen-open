# 60 秒演示视频脚本

目标：让没看过项目的人在 60 秒内理解“录音进、纪要出、数据不出门”，
并产生“我也要装一个”的冲动。手机竖屏或 16:9 均可，建议 16:9。

## 分镜

| 时间 | 画面 | 台词/字幕 |
|---|---|---|
| 0–5s | 标题卡：JKinco Listen · 本地会议纪要 | “会议纪要，为什么要上传云端？” |
| 5–12s | 插入 U 盘/拖入一段录音 | “把工地例会的录音拖进来。” |
| 12–22s | 进度条：转写 → 场景识别 → 纪要生成 | “本地 FunASR 转写，本地大模型生成纪要。” |
| 22–32s | 展示工程例会模板纪要 | “自动识别成工程例会格式：进度、质量、安全、待办。” |
| 32–40s | 点击导出 Word/PDF | “一键导出原版式 Word / PDF。” |
| 40–48s | 关掉 Wi-Fi，再操作一遍 | “全程本地，断网也能用。” |
| 48–55s | 打开终端，敲 docker compose up | “部署？一条命令。” |
| 55–60s | 二维码 + 仓库地址 | “开源免费，点个 Star。” |

## 制作清单

- 用真实录音（30–60 秒工地例会片段，注意脱敏）；
- 字幕用中英双语；
- 标题卡用 `docs/social-preview.png` 同款视觉；
- 上传 Bilibili（国内）+ YouTube（海外），两个链接都放进发布文案。
